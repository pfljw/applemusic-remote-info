뮤직 리모컨 베타 안내

USB DAC를 꽂은 iPad로 애플 뮤직을 듣는 분을 위한 리모컨입니다. 휴대폰 브라우저(안드로이드·아이폰)나 iPad 화면에서 선곡하고 재생을 조절합니다.

소리가 지나가는 길

휴대폰 브라우저 — Wi-Fi → iPad · 뮤직 리모컨 — 조종 → iPad · 음악 앱 — USB → DAC

소리는 iPad의 음악 앱이 직접 냅니다. 리모컨은 "이 곡 재생" 같은 명령만 전달하므로, 지금 쓰시는 비트퍼펙트 출력 경로는 그대로입니다.

준비물

  • iPad (iPadOS 16 이상). iPhone에서도 동작합니다.
  • Apple Music 구독
  • iPad와 같은 Wi-Fi에 연결된 휴대폰
  • USB DAC (권장). 화면을 켜 둔 채 충전하려면 PD 충전 겸용 USB-C 허브가 있으면 좋습니다.

설치

  1. iPad에 TestFlight 설치

    App Store에서 Apple의 TestFlight 앱을 받습니다.

  2. 초대 링크 열기

    베타 참여 링크를 iPad에서 열고, TestFlight에서 수락 → 설치를 누릅니다.

  3. 처음 실행

    Apple Music 접근, 로컬 네트워크, 알림 요청을 모두 허용합니다. 알림은 앱이 화면 뒤로 갔을 때 알려 주는 데 씁니다.

  4. 휴대폰 연결

    iPad 아래쪽 설정 탭 → 휴대폰 연결에 나오는 QR을 휴대폰 카메라로 찍으면 리모컨이 열립니다. PIN은 자동으로 들어갑니다. 브라우저 메뉴의 "홈 화면에 추가"를 쓰면 앱처럼 쓸 수 있습니다.

꼭 알아 둘 점

iPad에서 뮤직 리모컨이 화면에 떠 있어야 휴대폰 리모컨이 작동합니다. 홈 화면으로 나가거나 화면이 잠기면 멈춥니다. 앱이 켜져 있는 동안은 자동 잠금을 막고, 설정 탭의 "화면 어둡게"로 밝기를 최저로 내릴 수 있습니다.

볼륨

iPad 볼륨은 최대로 두고 DAC나 앰프에서 조절하세요. iPad에서 줄이면 DAC에 따라 비트퍼펙트가 깨질 수 있어서 리모컨에는 볼륨 조절을 넣지 않았습니다.

음질 표시

재생 화면 아래에 iPad가 DAC로 내보내는 실제 샘플레이트가 나옵니다(예: 출력 96 kHz · USB). 48 kHz를 넘으면 "고해상도 무손실"로 표시합니다. 고해상도로 들으려면 iPad 설정 → 음악 → 오디오 품질에서 고해상도 무손실을 켜세요.

플레이리스트

직접 만든 플레이리스트에는 곡을 추가할 수 있습니다. 이름 바꾸기·순서·곡 빼기는 리모컨에서 만든 플레이리스트(✎ 표시)만 됩니다. 플레이리스트 삭제는 Apple이 외부 앱에 허용하지 않아 iPad 음악 앱에서 해야 합니다.

가사

Apple은 가사를 외부 앱에 주지 않아서 공개 가사 데이터베이스(LRCLIB)에서 찾아옵니다. 없는 곡도 있습니다.

클래식·재즈

둘러보기 위쪽에서 Apple Music · 클래식 · 재즈를 바꿀 수 있습니다. Apple Music Classical 앱 자체는 조종할 수 없어서, 같은 음원을 음악 앱으로 재생하는 클래식 모드를 따로 두었습니다.

안 될 때

"iPad 앱이 응답하지 않습니다"라고 나와요

iPad에서 뮤직 리모컨이 화면에 떠 있는지, 휴대폰과 iPad가 같은 Wi-Fi인지 확인한 뒤 배너의 "다시 연결"을 누르세요.

휴대폰에서 주소가 열리지 않아요

iPad 설정 탭 → 휴대폰 연결에 나오는 http://192.168.x.x:8080 형태의 주소를 브라우저에 그대로 입력하세요. 공유기가 iPad 주소를 바꾸면 QR을 다시 찍어야 합니다.

Mac·iPhone의 Chrome에서만 안 열려요 (Safari는 돼요)

Apple 기기는 앱마다 '로컬 네트워크'(같은 Wi-Fi의 기기에 접속하는 권한)를 따로 묻습니다. Safari는 처음부터 허용돼 있지만, Chrome·Edge·Whale은 처음 물을 때 허용하지 않았으면 iPad 주소에 접속하지 못합니다.

Mac: 시스템 설정 → 개인정보 보호 및 보안 → 로컬 네트워크에서 Google Chrome을 켜고, Chrome을 완전히 종료(⌘Q)했다가 다시 여세요.
iPhone·iPad: 설정 → Chrome → 로컬 네트워크를 켜세요.

PIN을 물어봐요

iPad 설정 탭 → 휴대폰 연결 화면에 4자리 PIN이 있습니다. 여러 번 틀리면 1분 동안 막힙니다.

"고해상도 무손실"이 안 나와요

iPad 설정 → 음악 → 오디오 품질에서 고해상도 무손실이 켜져 있는지, 출력이 USB DAC인지 확인하세요. 곡 자체가 무손실(최대 48 kHz)까지만 있는 경우도 많습니다.

의견 보내기

TestFlight 앱 → 뮤직 리모컨 → 베타 피드백 보내기를 쓰거나, iPad에서 스크린샷을 찍으면 나오는 TestFlight 피드백 버튼으로 화면과 함께 보낼 수 있습니다. 동호회 게시판에 남겨 주셔도 됩니다. 앱은 개인정보를 수집하지 않습니다(개인정보처리방침). 베타 빌드는 올라온 날부터 90일이 지나면 만료되고, 그 전에 새 빌드가 올라오면 TestFlight에서 업데이트할 수 있습니다.

문의: 준비 중

Apple Music은 Apple Inc.의 상표입니다. 뮤직 리모컨은 Apple과 관계없는 개인 프로젝트입니다.
