뮤직 리모컨

USB DAC를 꽂은 iPad로 Apple Music을 듣는 분을 위한 리모컨입니다. 같은 Wi-Fi의 휴대폰 브라우저(안드로이드·아이폰)나 iPad 화면에서 선곡하고 재생을 조절합니다.

TestFlight로 베타 참여 설치·사용 안내

소리가 지나가는 길

휴대폰 브라우저— Wi-Fi → iPad · 뮤직 리모컨— 조종 → iPad · 음악 앱— USB → DAC

소리는 iPad의 음악 앱이 직접 냅니다. 리모컨은 명령만 전달하므로 비트퍼펙트 출력 경로가 그대로입니다.

할 수 있는 것

  • 검색, 보관함(플레이리스트·아티스트·앨범·노래), 즐겨찾는 노래
  • 재생 조절, 가사(시간에 맞춰 따라감), 곡 목록, 잠자기 타이머
  • 클래식 홈(작곡가·시대·작품별 녹음 비교)과 재즈 홈(시대·스타일·레이블·명반)
  • iPad가 DAC로 내보내는 실제 샘플레이트 표시 (예: 출력 96 kHz · USB)
  • 내 플레이리스트에 곡 추가, 리모컨에서 만든 플레이리스트 편집

필요한 것: iPad 또는 iPhone (iOS 16 이상), Apple Music 구독, 같은 Wi-Fi의 휴대폰. USB DAC 권장.
